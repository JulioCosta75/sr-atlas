# Sr. Atlas Free

Sr. Atlas Free is a MetaTrader 5 account supervisor for Windows. It reads and monitors your MT5 terminal and accounts and shows their state on a local dashboard. It is read-only: it does not open, modify or close trades.

## Requirements

- Windows 10 or Windows 11
- MetaTrader 5 installed

## Installation

1. Download `Atlas_Setup.exe` from the [Releases](https://github.com/JulioCosta75/sr-atlas/releases/latest) page.
   Direct link: https://github.com/JulioCosta75/sr-atlas/releases/latest/download/Atlas_Setup.exe
2. Run `Atlas_Setup.exe` and follow the installer.

## Verify the download

The installer is code-signed. Its SHA256 checksum is:

```
3e4f793a6cfe6481bbfff70fb25d06b879dd5cdd3259cc9ac7115d794531872e
```

To check it in PowerShell:

```powershell
Get-FileHash .\Atlas_Setup.exe -Algorithm SHA256
```
